#### 1. Summary of Concepts Covered

* **Higher-Order Functions & Closures:**
  * Leveraging inner functions to retain access to outer scope variables (closures) across asynchronous or deferred execution phases.
* **Function Chaining (`pipe` vs. `compose`):**
  * **`pipe` (Left-to-Right):** Passing data sequentially through an array of functions where the output of function $N$ becomes the input for function $N+1$.
  * **`compose` (Right-to-Left):** Evaluating function operations inside-out, mirroring mathematical function composition $f(g(x))$.
* **Argument Manipulation (`partial` vs. `curry`):**
  * **`partial` Application:** Pre-binding a subset of initial arguments upfront (`presetArgs`) and returning a function that accepts the remaining arguments (`laterArgs`) to execute the underlying target function.
  * **`curry` Transformation:** Converting a multi-argument function expecting $N$ parameters into a recursive chain of single (or multi) argument invocations until $\text{args.length} \ge \text{fn.length}$.
* **Arity & Unary Pipelines:**
  * Understanding that functional pipelines rely on single-input/single-output transformations, and using `partial` or `curry` to adapt multi-parameter functions to fit inside a `pipe`.

  * **Takeaway:** General utility functions like `pipe`, `partial`, and `curry` must remain pure argument conduits. They do not transform or evaluate business logic themselves; their sole responsibility is managing function invocation and argument passing.

#### 1. Summary of Concepts Covered

* **Observer Pattern & Event-Driven Architecture:**
  * Decoupling state changes (publishers) from reactive behaviors (subscribers/listeners) using an intermediary event registry object.
* **Event Registry Design (`this.events`):**
  * Mapping string event names (labels) to arrays of callback functions (`this.events[event] = []`), allowing multiple independent listeners to subscribe to the same event.
* **Wildcard & Global Logging (`'*'`):**
  * Implementing fallback/global event capture where generic audit loggers can listen to *all* emitted events across the system while receiving both the event name and payload data `(event, ...args)`.
* **Self-Destructing Callbacks (`once`):**
  * Using wrapper closures to register temporary listeners that execute their target logic upon trigger and immediately unsubscribe themselves via `this.off()`.
* **Subclassing & Reactive Data Stores (`UserStore`):**
  * Extending base utility classes via OOP inheritance (`UserStore extends EventEmitter`) and triggering event emissions (`this.emit()`) following internal state mutations (`this.storage`).

---

#### 2. Weakness Analysis & Common Misconceptions

* **Array-Based Events vs. Single Function Overwrites:**
  * **Observation:** Initial mental models attempted to assign a single function directly to an event key (`this.events[event] = listener`), which would overwrite existing listeners instead of appending them.
  * **Takeaway:** Event channels are collections. Events must store an *array* of functions to allow multiple subscribers to respond to a single trigger.
* **Registry Loops vs. Key Verification:**
  * **Observation:** Initial `on` and `off` logic attempted to iterate over existing keys using `for (let i of Object.keys(this.events))`, causing empty objects (`{}`) to skip execution entirely and prevent new event creation.
  * **Takeaway:** Avoid unnecessary iterations when searching object keys. Direct property checks (`if (!this.events[event])`) directly handle initialization and lookup.
* **Deferred Registration vs. Immediate Execution (`once`):**
  * **Observation:** Initial attempts at `once()` executed the listener immediately upon call or attempted to remove the original listener reference instead of the wrapper reference.
  * **Takeaway:** `once()` is a registration phase method. It places a wrapper function into the registry. When `emit()` eventually fires, the wrapper calls the original listener and removes *itself* (`this.off(event, wrapper)`).
* **Publisher vs. Subscriber Roles (`UserStore`):**
  * **Observation:** Attempted to call `on()` and `off()` inside `UserStore` mutation methods (like `userAdded`).
  * **Takeaway:** Data stores act as *publishers* (triggering actions via `this.emit()`). External consumers act as *subscribers* (registering interest via `store.on()`).

### TASK 7: Virtual Scroll for Large Lists — Final Note

#### Summary of Concepts Covered
- **Virtual Scrolling (DOM Windowing):** Rendering massive datasets (10,000+ items) efficiently by mounting only the visible viewport slice into the DOM tree, avoiding memory bloat and layout engine degradation.
- **Phantom Spacer Architecture:** Decoupling scroll container height from active DOM elements using a tall, zero-content phantom element (`height = totalItems * itemHeight`) to mimic native document scrollbar mechanics.
- **Dynamic Index & Buffer Math:** Computing target array slice ranges dynamically on scroll (`scrollTop / itemHeight`) with a safety buffer offset to prevent white space flickering during rapid scrolling.
- **Compositor Positioning via GPU (`transform: translateY`):** Shifting the visible content container without triggering layout passes or reflow loops, leveraging hardware acceleration to maintain smooth frame rates above 50–60 FPS.
- **Scroll Event Throttling (`requestAnimationFrame`):** Binding frame-rate-aligned scroll handling to avoid scroll jank and layout feedback loops.

- **Layout Feedback Loops (Scroll Jank):** Attempting to incrementally insert (`append`) and remove (`remove`) individual DOM elements relative to scroll direction. Modifying internal element flow inside a scroll container mutates `scrollTop`, firing secondary scroll events that cause jitter loops.

- **Viewport vs. Spacer Height Confusion:** Setting `style.height` directly on the scroll container instead of an inner phantom element, breaking container overflow scroll boundaries.
- **Hardcoded Limit Guarding:** Constraining render checks with static limits (e.g., `end < 1000`) rather than clamping bounds dynamically with `Math.min(calculatedEnd, totalItems)`.
