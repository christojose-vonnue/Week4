# Week 4 — JavaScript SPA

## Recipe Browser SPA

A single-page Recipe Browser application built using vanilla JavaScript.

The application demonstrates client-side routing, state management, reducers, reusable components, local storage, recipe operations, theme switching, and automated testing with Vitest.

## Live Demo

[Recipe Browser SPA](https://christojose-vonnue.github.io/Week4/)

## Tech Stack

- HTML
- CSS
- JavaScript
- Vitest
- jsdom

## Features

- Client-side SPA routing
- Dynamic recipe detail routes
- Recipe search and filtering
- Add, update, and delete recipes
- Local storage persistence
- Theme switching
- Reusable UI components
- State management with reducer and store
- Automated tests
